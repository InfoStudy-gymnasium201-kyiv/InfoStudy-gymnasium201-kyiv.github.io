Алгоритми опрацювання табличних величин

Знаходження суми значень елементів; суми або кількості елементів, що задовольняють заданим умовам.

Інформатика, 9 клас

Що таке табличні величини?

Таблична величина (масив) — це впорядкована сукупність фіксованої кількості значень одного типу, що мають спільне ім'я.

  • Кожен елемент має свій індекс (номер).
  • Доступ до значення здійснюється через ім'я та індекс: A[i].

Приклад масиву A:

Індекс 0 1 2 3
Значення 10 -5 22 14

Алгоритм знаходження суми

Для обчислення суми всіх елементів масиву використовується змінна-накопичувач (наприклад, S).

Основні кроки:

  1. Надати змінній S початкове значення 0.
  2. Використати цикл для перебору всіх елементів масиву.
  3. На кожному кроці додавати поточний елемент до суми: S := S + A[i].

Приклад коду: Сума (Python)

# Початкові дані
numbers = [10, 15, 20, 5, 30]
s = 0 # Змінна для суми

# Цикл для накопичення результату
for x in numbers:
    s = s + x

print("Сума елементів:", s)
# Результат: 80

Зауважте: у Python також можна просто використати вбудовану функцію sum(numbers).

Сума елементів за умовою

Часто потрібно знайти суму не всіх елементів, а лише тих, що задовольняють певній логічній умові (наприклад, лише додатні або лише парні).

Логіка:

ЯКЩО (умова справджується) ТО (додати до суми)

Приклади умов:

  • A[i] > 0 — додатні
  • A[i] < 0 — від'ємні
  • A[i] % 2 == 0 — парні
  • A[i] > 100 — більші за 100

Приклад: Сума додатних чисел

A = [5, -3, 10, -2, 8, 0]
s_pos = 0

for i in range(len(A)):
    if A[i] > 0: # Перевірка умови
        s_pos = s_pos + A[i]

print("Сума додатних елементів:", s_pos)
# Результат: 23 (5 + 10 + 8)

Знаходження кількості елементів

Алгоритм підрахунку кількості (лічильник) схожий на знаходження суми, але замість значення елемента ми додаємо 1.

Сума

S = S + A[i]

Додаємо вміст "коробки"

Кількість

K = K + 1

Рахуємо саму "коробку"

Приклад: Кількість парних елементів

array = [12, 7, 24, 11, 8, 3]
count = 0

for x in array:
    if x % 2 == 0: # Якщо ділиться на 2 без остачі
        count = count + 1

print("Кількість парних чисел:", count)
# Результат: 3 (12, 24, 8)

Складні умови

Елементи можуть фільтруватися за декількома критеріями одночасно за допомогою операторів AND (та) або OR (або).

# Приклад: Сума елементів в діапазоні [10, 50]

if A[i] >= 10 and A[i] <= 50:

S = S + A[i]

Порада: Завжди ініціалізуйте змінні (S=0, K=0) ПЕРЕД циклом, інакше програма видасть помилку.

Висновки та перевірка

Запам'ятайте:

  • Сума: S = S + елемент
  • Кількість: K = K + 1
  • Умова: використовуємо if всередині циклу
