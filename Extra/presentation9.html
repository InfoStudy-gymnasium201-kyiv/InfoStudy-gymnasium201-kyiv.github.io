Урок Інформатики

Складання і виконання алгоритму пошуку значень таблиці

Навчимося знаходити потрібні дані у списках Python, використовувати цикли та умови для ефективного аналізу табличних величин.

Мова: Python 3.x
Об'єкт: Список (list)

1. Табличні дані в Python

Для представлення таблиці (одновимірного масиву) в Python використовують тип даних Список (list).

Важливо знати:

  • ● Індексація починається з нуля.
  • ● Щоб звернутися до третього елемента списку a, пишемо a[2].

# Створення списку

a = [10, 20, 30, 40]
print(a[2]) # Виведе 30
Увага! Якщо вказати індекс, що перевищує довжину списку, виникне помилка IndexError.

2. Що таке лінійний пошук?

Лінійний пошук — це найпростіший алгоритм, який полягає у послідовному перегляді кожного елемента таблиці від першого до останнього.

🔍

Взяти перший елемент

⚙️

Крок 2

Перевірити умову

➡️

Крок 3

Перейти до наступного

Для дізнання кількості елементів у списку використовують функцію len(a).

3. Перебір елементів: Цикл FOR

Для послідовного перегляду всіх елементів таблиці найчастіше використовують цикл for.

  • Через елементи:
    for x in a: (бере саме значення)
  • Через індекси:
    for i in range(len(a)): (бере номер місця) 
# Приклад перебору
a = [5, 12, 7, 21]

for x in a:
    if x > 10:
        print("Знайдено:", x)

4. Пошук за умовою

Для знаходження значень, що відповідають критеріям, використовують команду if всередині циклу.

Одна умова:

if a[i] > 10:

Знайде всі числа, більші за 10.

Дві умови (одночасно):

if x > 0 and x < 100:

Оператор and вимагає виконання обох умов.

5. Пошук найбільшого (MAX)

При пошуку найбільшого елемента в таблиці, важливо правильно обрати початкове значення для змінної-результату.

Золоте правило:

Змінній max (або m) перед початком пошуку доцільно присвоїти значення першого елемента таблиці (a[0]).

Це гарантує, що ми порівнюємо дані саме з тієї таблиці, яку опрацьовуємо.

6. Накопичення результату

Лічильник (Кількість)

Рахуємо, скільки разів трапився елемент.

k = 0 # старт
k = k + 1 # крок

Суматор (Сума)

Додаємо значення до загального кошика.

s = 0 # старт
for x in a:
    s = s + x

7. Оптимізація: Команда BREAK

Команда break використовується для дострокового виходу з циклу.

Це корисно, коли нам потрібно лише знайти, чи є в списку хоча б одне таке значення. Як тільки ми його знайшли — далі шукати немає сенсу.

for x in students:
  if x == "Ivan":
    print("Є!")
    break # зупинка

8. Пастки та помилки

!

IndexError

Виникає, якщо ви намагаєтеся отримати елемент за індексом, якого не існує (наприклад, a[10] у списку з 5 елементів).

?

Складні умови

Завжди перевіряйте, чи правильно ви вказали індекси в if a[i] > 10:. Помилка if a > 10: (порівняння списку з числом) призведе до збою програми.

Готові до тесту?

Короткий чек-лист:

  • ✅ Таблиця = list
  • ✅ Цикл перегляду = for
  • ✅ Розмір списку = len(a)
  • ✅ Дострокова зупинка = break

Алгоритм пошуку:

  • 1. Почати з першого елемента (індекс 0).
  • 2. Переглянути лінійно (for).
  • 3. Перевірити умову (if).
  • 4. Змінити результат (k = k + 1 або s = s + x).

Успіхів у тестуванні!
