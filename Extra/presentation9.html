Пошук значень у табличних величинах

Складання та виконання алгоритмів пошуку в навчальному середовищі програмування

Інформатика 9 клас

Завдання пошуку

Пошук у масиві — це процес знаходження елементів, що мають певну властивість або дорівнюють заданому значенню.

Основні типи задач:

  • ✓ Знаходження конкретного значення
  • ✓ Пошук найбільшого/найменшого (Min/Max)
  • ✓ Знаходження індексу елемента
🔍

Алгоритм має перевірити кожен елемент, доки не знайде потрібний або не дійде до кінця.

Лінійний пошук (Linear Search)

Це найпростіший метод, де ми послідовно порівнюємо кожен елемент масиву з шуканим значенням (ключем).

1

Беремо перший елемент

2

Порівнюємо з ключем

3

Повторюємо для наступного

Важливо: Якщо ми знайшли елемент, ми можемо зупинити цикл (використати break), щоб зберегти час.

Реалізація на Python

data = [12, 45, 7, 23, 56, 10]
key = 23 # Що ми шукаємо
found = False

for i in range(len(data)):
    if data[i] == key:
        print(f"Знайдено на позиції: {i}")
        found = True
        break

if not found:
    print("Елемент не знайдено")

У цьому прикладі ми використовуємо found як "прапорець" (flag).

Пошук екстремальних значень

Для пошуку максимуму або мінімуму:

  1. Припускаємо, що перший елемент (індекс 0) і є шуканим.
  2. Порівнюємо його з усіма іншими.
  3. Якщо знаходимо більший (для Max) — оновлюємо значення.

Логіка Max:

max_val = A[0]

якщо A[i] > max_val:

max_val = A[i]

Приклад: Пошук максимуму

numbers = [3, 18, 42, 5, 29, 11]

# 1. Початкове припущення
max_value = numbers[0]

# 2. Перебір решти елементів
for x in numbers:
    if x > max_value:
        max_value = x

print("Найбільше число:", max_value)
# Результат: 42

Аналогічно працює пошук мінімуму, тільки знак порівняння змінюється на <.

Помилка: Не забувайте перевіряти, чи взагалі існує такий елемент у таблиці, щоб програма не виводила пустий результат.

Знаходження позиції (індексу)

Часто значення саме по собі менш важливе, ніж його місце в таблиці.

temps = [20, 22, 25, 19, 21]
max_t = temps[0]
pos = 0

for i in range(len(temps)):
    if temps[i] > max_t:
        max_t = temps[i]
        pos = i # Запам'ятовуємо індекс

print(f"Макс. температура {max_t} була в день №{pos+1}")
