Списки в Python: Повний гід по роботі з масивами

У програмуванні часто виникає потреба опрацьовувати не одну-дві змінні, а цілі набори даних. У мові Python для цього використовують списки (list) — впорядковані послідовності елементів будь-яких типів.

Спробувати візуалізатори Пройти тест
1

Створення списків

Списки оголошуються за допомогою квадратних дужок [ ], а елементи всередині розділяються комами. Список може містити елементи одного типу або бути мішаним.

Приклади оголошення списків 
# Порожній список
empty_list = []

# Список рядків
weekdays = ['Monday', 'Tuesday', 'Wednesday', 'Thursday', 'Friday']

# Мішаний список (різні типи даних)
mix = ['Oksana', 15, 165.5]

# Вкладений список (матриця)
matrix = [[0, 0, 1], [0, 1, 0]]

Анатомія списку в пам'яті

Список зберігає послідовність посилань на об'єкти. Кожен елемент може бути будь-якого типу:

mix =
'Oksana' (str) , 15 (int) , 165.5 (float)
matrix =
[0, 0, 1] , [0, 1, 0]
Порада: На відміну від масивів у деяких інших мовах (наприклад, C++), списки в Python є гетерогенними — вони можуть містити різні типи даних одночасно!
2

Індексація: як звернутися до елемента

Кожен елемент у списку має свій порядковий номер — індекс. Нумерація починається з 0. Також можна використовувати від’ємні індекси: -1 посилається на останній елемент, -2 — на передостанній тощо.

Інтерактивний дослідник індексів

Натисніть на елемент списку, щоб побачити його додатний та від'ємний індекси

colors = ['red', 'green', 'blue', 'yellow', 'purple']
Команда звернення за додатним індексом:
colors[0]
Результат: 'red'
Команда звернення за від'ємним індексом:
colors[-5]
Результат: 'red'

Щоб отримати частину списку (підсписок), використовують синтаксис список[start:end:step]. Зауважте: елемент із індексом end не включається у результат!

Базові операції зі списками

+

Конкатенація

Об'єднання двох списків в один послідовний новий список.

a = [1, 2]; b = [3, 4]
print(a + b)
# [1, 2, 3, 4]
*

Дублювання

Повторення елементів списку вказану кількість разів.

a = [1, 2]
print(a * 3)
# [1, 2, 1, 2, 1, 2]
len

Довжина списку

Функція len() повертає загальну кількість елементів.

a = [1, 2]
print(len(a))
# 2
5

Редагування та зміна вмісту

На відміну від рядків (string) або кортежів (tuple), списки в Python є змінюваними (mutable) об’єктами. Ви можете додавати, видаляти та змінювати елементи "на місці" без створення нового списку.

Дія Команда / Метод Приклад коду Опис
Зміна елемента список[індекс] = значення a[2] = 'f' Замінює елемент за вказаним індексом
Додавання в кінець .append(значення) a.append('e') Додає новий елемент в самий кінець списку
Вставка за індексом .insert(індекс, значення) a.insert(1, 'b') Вставляє елемент на позицію, зсуваючи інші
Видалення за індексом del список[індекс] del a[2] Видаляє елемент за вибраним індексом
Видалення за значенням .remove(значення) a.remove('b') Видаляє перше входження вказаного значення
Інтерактивна пісочниця

Пісочниця модифікації списку

Поточний стан списку a:
1. Додати в кінець (.append)
2. Вставити (.insert)
3. Замінити за індексом
4. Видалити за значенням (.remove)
5. Видалити за індексом (del)
6. Витягнути останній (.pop)
Остання виконана команда: a = ['a', 'c', 'd']
6

Копіювання списків: Посилання vs Копія

Важлива пастка для початківців! Якщо просто написати b = a, обидві змінні будуть посилатися на один і той самий список у пам'яті. Зміна елемента в a призведе до автоматичної зміни в b!

Щоб створити справді незалежну копію списку, використовуйте один із трьох способів:

1 b = a.copy()
2 b = list(a)
3 b = a[:]

Шпори: Всі методи списків Python

Швидкий довідник найважливіших функцій та методів

.append(x)

Додає елемент x у кінець списку.

.extend(iterable)

Розширює список елементами з іншого списку/послідовності.

.insert(i, x)

Вставляє елемент x на позицію i.

.remove(x)

Видаляє перший елемент зі значенням x.

.pop([i])

Видаляє і повертає елемент за індексом i (за замовчуванням останній).

.clear()

Видаляє всі елементи зі списку (робить його порожнім).

.index(x)

Повертає індекс першого елемента зі значенням x.

.count(x)

Повертає кількість елементів зі значенням x.

.sort()

Сортує елементи списку за зростанням на місці.
