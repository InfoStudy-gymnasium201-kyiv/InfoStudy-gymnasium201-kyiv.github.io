Розділ 1

Актуалізація знань

Пригадай перед вивченням:

  • • Які комп'ютерні пристрої використовують для роботи з даними (введення, зберігання, виведення);
  • • Які існують основні інформаційні процеси (пошук, збір, опрацювання, зберігання, передавання, захист);
  • • Які базові функції виконує операційна система комп'ютера.
Розділ 2

Що робить комп'ютер комп'ютером?

Будь-яка сучасна обчислювальна система працює за чітким принципом інформаційного циклу: отримання даних, їхнє збереження, обробка та видача результату.

Розділ 3

Класифікація пристроїв сучасного ПК

Люди різних професій використовують комп'ютер, щоб вводити дані, зберігати їх, працювати з ними та передавати іншим людям. Для кожного із цих інформаційних процесів використовують різні пристрої комп'ютера, які ділять на внутрішні та зовнішні.

Схема • Мал. 3.2 Пристрої сучасного персонального комп'ютера

Внутрішні пристрої

Пристрій опрацювання: Процесор (CPU)
Пристрої запам me'ятовування: Материнська плата, Жорсткий диск (HDD/SSD), Оперативна пам'ять

Зовнішні пристрої

Пристрої введення: Клавіатура, Миша, Вебкамера, Мікрофон, Сканер
Пристрої виведення: Монітор, Навушники, Принтер, Колонки

Розділ 4

Складові комп'ютерної системи

Комп'ютер як один із пристроїв, що забезпечує функціонування інформаційної системи, об'єднує дві головні взаємозалежні складові.

Схема • Мал. 3.3 Структура комп'ютерної системи
Апаратна складова

Hardware («Залізо»)

  • • Фізичні пристрої (процесор, пам'ять, диски)
  • • Технічні засоби зв'язку та мережеве обладнання
  • • Периферійні пристрої введення/виведення
Інформаційна складова

Software & Data

  • • Програми (операційна система, утиліти, додатки)
  • • Дані (файли, документи, бази даних)
  • • Інструкції та правила опрацювання

[ Плейсхолдер зображення: Мал. 3.3 — Комп'ютер: Апаратна складова + Інформаційна складова ]

Розділ 5

Що таке Програмне Забезпечення?

Визначення терміна

Програмне забезпечення (Software) — це сукупність програм і правил, а також документації щодо функціонування комп'ютера для опрацювання даних.

Без програм комп'ютер не зможе виконувати жодної функції з даними, а буде лише набором електронних та механічних пристроїв.

Схема • Мал. 3.4 Класифікація програмного забезпечення
1. Системне ПЗ

Керує апаратними засобами, створює платформу для прикладних програм та забезпечує взаємодію з користувачем.

• Операційні системи
• Драйвери пристроїв
• Утиліти (службові)
2. Прикладне ПЗ

Призначене для виконання конкретних користувацьких завдань (текст, графіки, обчислення, навчання).

• Загального призначення
• Спеціального призначення
• Офісні пакети
3. Інструментальне ПЗ

Використовують для проєктування, розробки, налагодження та тестування нових програм.

• Мови програмування
• Середовища розробки (IDE)
• Засоби проєктування

[ Плейсхолдер зображення: Мал. 3.4 — Класифікаційна схема програмного забезпечення ]

Розділ 6

Детальний огляд категорій ПЗ

Системне програмне забезпечення

Забезпечує взаємодію інших програм із апаратним забезпеченням комп'ютера.

Драйвери: Програми, що забезпечують взаємозв'язок операційної системи та інших програм з конкретними апаратними пристроями (відеокартою, принтером, мишею тощо).
Службові програми (утиліти): Автоматизують перевірку й налаштування ПК, підвищують ефективність роботи. До них належать архіватори (7-Zip, WinRAR), антивірусні програми (Zillya!, Norton, McAfee).

Прикладне програмне забезпечення

Загального призначення

Використовується більшістю користувачів для вирішення щоденних завдань: текстові й графічні процесори, табличні процесори, мультимедійні програвачі, браузери, електронні енциклопедії.

Спеціального (професійного) призначення

Для вузькоспеціалізованих задач фахівців різних галузей: математичні обчислення (MathLab, MathCad), 3D-моделювання й анімація (3D MAX Studio), системи обліку товарів у магазинах тощо.

Інструментальне програмне забезпечення

Спеціальні програми для розробників. До них належать системи програмування (мови C, C++, C#, Python) та інтегровані середовища розробки (наприклад, Microsoft Visual Studio).

Розділ 7

Рівні взаємодії користувача з ПК

Користувач взаємодіє з апаратним забезпеченням не напряму, а через багатошарову структуру програмних інтерфейсів.

Схема • Мал. 3.5 Рівні взаємодії користувача та складових ПК
Рівень 1: Користувач / Користувачка
↓ Взаємодія з інтерфейсом програми
Рівень 2: Прикладна програма (Текстовий редактор, Браузер тощо)
↓ Виклики системних функцій
Рівень 3: Операційна система / Системні утиліти / Драйвери
↓ Команди керування пристроями
Рівень 4: Апаратне забезпечення (процесор, память, диски, принтер)

[ Плейсхолдер зображення: Мал. 3.5 — Багаторівнева схема взаємодії користувача з пристроями ]

Розділ 8

Перегляд пристроїв та програм в ОС

Сучасна операційна система дає змогу переглядати список підключеного обладнання та встановленого софту, а також керувати ним.

1. Інстальовані програми (Мал. 3.6)

Перегляд списку встановленого ПЗ через Налаштування → Програми → Інстальовані програми. Тут можна дізнатися розмір програми, версію та видалити її за потреби.

[ Плейсхолдер зображення: Мал. 3.6 — Вікно «Інстальовані програми» Windows ]

2. Диспетчер пристроїв (Мал. 3.7)

Перегляд апаратних складових та їхніх драйверів через системну утиліту Диспетчер пристроїв (Device Manager).

[ Плейсхолдер зображення: Мал. 3.7 — Вікно «Диспетчер пристроїв» ]

📌 Пам'ятай: Будь-яка програма перед використанням повинна бути встановлена (інстальована) у системі й взаємодіяти з операційною системою.
Розділ 9

Підсумки та оцінювання знань

Головні висновки параграфа:

  • ✓ Інформаційна система комп'ютера складається з двох невід'ємних частин: апаратної (Hardware) та інформаційної / програмної (Software).
  • ✓ Програмне забезпечення поділяється на системне (ОС, драйвери, утиліти), прикладне (загального й спеціального призначення) та інструментальне (мови й середовища програмування).
  • ✓ Взаємодія користувача з комп'ютером відбувається поетапно: Користувач → Прикладна програма → ОС та драйвери → Апаратний пристрій.

Запитання для самоперевірки:

  1. Що станеться з комп'ютером, якщо вилучити з нього все програмне забезпечення?
  2. Для чого потрібні драйвери пристроїв і до якої групи ПЗ вони належать?
  3. Чим прикладне ПЗ загального призначення відрізняється від спеціального? Наведіть приклади.
  4. Які пристрої входять до групи внутрішніх, а які — до зовнішніх?
